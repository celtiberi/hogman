Hosting HTTPS servers

Anything that runs over HTTPS (port 443) works inside a pen. One command attaches a local web app, dev server, LAN service, or static directory with its own private name and a real Let's Encrypt padlock.

$ ~/hogman-join share cooler-1 3000

• Adding a server for cooler-1.store-north.pens.hogman.network (gary)
• Proxying http://127.0.0.1:3000 as https://cooler-1.store-north.pens.hogman.network

✓ https://cooler-1.store-north.pens.hogman.network is up.
  Everyone in the pen can open it.
  Take it down and free the name: hogman-join share stop cooler-1

What you can share

TargetCommandBehavior
Local web server / app share blog 3000 Reverse-proxies http://127.0.0.1:3000 over HTTPS (WebSockets supported).
Static site / directory share archive ~/site Serves index.html (or a directory listing) over HTTPS inside Go's os.Root sandbox.
Service on your LAN share media http://192.168.1.20:8096 Proxies an internal LAN HTTP service (NAS, media server, Home Assistant) into the pen without opening router ports.

Local dev servers with real HTTPS

Share a local dev server straight from your laptop so teammates or testers can hit it from anywhere without deploying publicly:

$ npm run dev
$ ~/hogman-join share demo 5173

Because the share terminates real TLS with a publicly trusted certificate, browser features that require HTTPS (service workers, secure cookies, camera/mic permissions) behave just like production. Requests forward X-Forwarded-For, -Host, and -Proto while preserving the upstream Host header so dev servers like Vite and Next.js accept them out of the box.

Already running Caddy or nginx with multiple sites behind it? Share its port (share app 8080) and let Hogman handle the pen name and TLS.

Keeping servers running

Foreground shares stop when you press Ctrl-C (keeping your name reserved until you stop it). To run persistently across logouts and reboots, add --background:

$ ~/hogman-join share blog 3000 --background

On macOS (launchd) and Linux (systemd user services), --background registers a login service automatically. On a headless Linux server where no user logs in at boot, run sudo loginctl enable-linger $USER once so user services start on boot. Pass --no-service if you only want a temporary background process until reboot.

Dedicated / always-on servers

A VPS, mini PC, or home server does not need to join as a personal member device to host sites:

  1. On your pen's home page, press Get a share link and copy the single-use server link (valid for 1 hour).
  2. On the server machine, download hogman-join and pass the link at the end of the share command: 
    $ ./hogman-join share forum 8080 'https://store-north.gate.hogman.network/join#k=…' --background

Always use a share link for servers, not a member invite link (an invite creates a new member).

Listing & taking down

$ ~/hogman-join share list
https://cooler-1.store-north.pens.hogman.network   http://127.0.0.1:3000  (running in the background)

$ ~/hogman-join share stop cooler-1
✓ https://cooler-1.store-north.pens.hogman.network is down, and the name is free again.

share stop shuts down the server node and releases the name. Leaving a pen stops all shares running on that computer first. In more than one pen? Pass --pen <zone>.

Names & how shares are isolated

  • Format: single label (lowercase letters, digits, dashes) becoming https://NAME.<pen>.pens.hogman.network. First come, first served; up to 50 names per member.
  • Separate server node: every share runs its own embedded tsnet server identity (tag:server) with its own local CertMagic TLS keypair. Your laptop itself still accepts zero inbound connections and opens zero host firewall ports.
  • Clean rollback on failure: if a brand-new share fails to obtain its first certificate, it tears down its server node and releases the name automatically.
  • Certificate Transparency: issued share hostnames appear in public CT logs; site contents never leave the encrypted mesh.
  • Platform note: Windows is built but untested and does not yet register a reboot service for background shares.

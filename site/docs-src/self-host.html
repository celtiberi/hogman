Self-hosting

Hogman is hosted-only for pen control planes (decision D-24): we run every pen's gate, registrar, and challenge DNS on hogman.network, and do not support running self-hosted pen servers or custom pen domains.

Where your things still run on your machines

Only the coordination control plane lives on our host. Everything you put inside a pen using hogman-join share (folders, photo galleries, wikis, apps) runs directly on your own laptop, home server, or VM and talks peer-to-peer over end-to-end encrypted WireGuard.

Open source to read and verify

The entire codebase is free software under AGPL-3.0 on GitHub so anyone can inspect how isolation, DNS-01 validation, and membership enforcement work. Every release binary is built exclusively by GitHub Actions from a public commit with SLSA build provenance:

$ gh attestation verify hogman-join --repo celtiberi/hogman

Operators who want to inspect how our hosted server is provisioned and run can read the operator guide and the Architecture & security page.

Joining a pen

You need a single-use invite link from a pen's keeper and a Mac or Linux computer.

Your first computer

  1. Open your invite link on the computer you want to join. Invites work once and expire after 7 days.
  2. Paste the command it shows into Terminal — it's the same short command for everyone in the pen: 
    $ curl -fsSL https://john-mcafee.gate.hogman.network/start | sh
    It asks for your invite link (the page has a Copy my invite link button), downloads hogman-join for your platform, verifies its published SHA-256 checksum, saves it as ~/hogman-join, and runs it. Your invite token never appears in your shell command or history. Read the script first, or expand the manual download steps on the join page.
  3. Pick your handle when asked (lowercase letters, digits, and dashes, 2–32 characters).
  4. You're in. hogman-join verifies the gate using your OS's built-in HTTPS trust store, confirms your pen's home page loads over HTTPS, configures your browser proxy, and opens it. Keep ~/hogman-join — you'll use it to host servers, update, and leave.

On a Mac, two prompts may pop up — both are expected:

  • "Allow hogman-join to find devices on local networks?" Either answer works. Allow lets devices on the same LAN talk directly (faster); Don't Allow routes encrypted traffic over the internet instead. Nothing on your LAN is exposed either way.
  • Your Mac's password, once, to set the system automatic proxy URL so browsers find pen names. If you skip it, hogman-join prints the URL to set by hand.

If setup stops part way (offline, DNS still propagating), fix the cause and run the same command again. If it stopped before redeeming the invite, the link is still unused; if after, the rerun detects the enrolled device and finishes setup.

Using a VPN

On macOS, Network Extension VPN apps (ProtonVPN, Mullvad, WireGuard, corporate VPNs) override the system automatic proxy setting while connected, so browsers stop seeing pen names even though hogman-join stays connected.

  • Firefox (works today, no extension needed): set Firefox's built-in Settings → Network Settings → Automatic proxy configuration URL to the http://127.0.0.1:<port>/proxy.pac URL printed by hogman-join. Pen names route to hogman-join while ordinary browsing stays on your VPN.
  • Chrome, Brave, Edge, and Firefox extension (developer preview): the companion extension in browser-ext/ is not yet published on the Chrome Web Store or Mozilla Add-ons. Developers can load it manually from browser-ext/dist/ (see browser-ext/README.md; note that Firefox removes temporary add-ons on restart, and Firefox Private Windows send pen names to public DNS unless Run in Private Windows is enabled for the extension).
  • Safari: Apple does not expose proxy APIs to Safari extensions, so pause your VPN while visiting pen sites in Safari.

How it connects

hogman-join runs a small userspace background process as your user (no TUN interface, no root daemon) that starts at login. It carries HTTPS (port 443) to pen names and nothing else (plain http:// requests redirect locally to HTTPS). Your regular internet, LAN, and any existing Tailscale setup stay untouched. See what Hogman deliberately doesn't do.

Browsers & CLI tools

Only programs using the pen's local proxy (e.g. http://127.0.0.1:21234) reach pen sites:

  • Browsers: on macOS, hogman-join sets the automatic proxy URL (never replacing a non-Hogman proxy). Joining multiple pens updates the combined proxy.pac automatically. On Linux, point your browser or desktop automatic proxy setting to the printed proxy.pac URL (one URL covers all joined pens; reload proxy settings after joining or leaving a pen).
  • curl (per command): 
    $ https_proxy=http://127.0.0.1:21234 curl https://deadmans-switch.john-mcafee.pens.hogman.network
    Don't export https_proxy for your whole shell — the proxy refuses every non-pen hostname.
  • git (per host): 
    $ git config --global http.https://git.john-mcafee.pens.hogman.network/.proxy http://127.0.0.1:21234

Adding more devices

On your pen's home page, press Add a device for a single-use link and QR code (valid for 1 hour). Open it on the second computer and run the command; it joins under your handle. Phone support is in progress.

To host a web server in the pen, you don't need a personal device link — see Hosting HTTPS servers.

Updating & leaving

$ ~/hogman-join update

Downloads the latest binary from your pen's gate (or a host you pass), verifies its SHA-256 against SHA256SUMS over HTTPS, restarts your pen's background agent and service-managed shares, and cleans up any legacy state. Use --pen ZONE if you're in more than one pen, or --dry-run to preview.

$ ~/hogman-join leave '<your pen link or zone>'

Stops any shares on this computer, shuts down the background connection, and clears its proxy config. Your membership stays active — keepers remove members.

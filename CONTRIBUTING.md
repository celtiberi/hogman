## Bug reports, questions, and ideas

Bug reports, questions, and design discussions are welcome in [GitHub Issues](https://github.com/celtiberi/hogman/issues). Include your OS, `hogman --version` output, and clear steps to reproduce when reporting a bug. **Never paste invite or device links (`#t=` / `#k=`) or logs containing them**, since those grant access to your pen.

## Security vulnerabilities

Please do **not** report security vulnerabilities in a public issue. Use **"Report a vulnerability"** under the [Security tab](https://github.com/celtiberi/hogman/security/advisories/new), or email `hogman-support@proton.me`. See [`SECURITY.md`](SECURITY.md) for scope and response details.

## External pull requests

We are not accepting external code pull requests without a signed Contributor License Agreement (CLA), so that copyright on this codebase remains cleanly under Galderwood LLC for dual-licensing.

We say this upfront so nobody spends a weekend writing a pull request we have to turn away. If you find a bug or have a change in mind, please open an Issue describing the problem (and your suggested approach, if you have one), and we will implement the fix ourselves. Security fixes follow the same rule: report the vulnerability privately, and we will write the fix.

One-time browser setup (Hogman never asks for your Mac or computer password)

        
    
          
  • Set your browser's automatic proxy URL once using the http://127.0.0.1:<port>/proxy.pac address printed by hogman (only pen sites use it; normal browsing goes direct):
            
    macOS: System Settings → Network → Wi-Fi (or Ethernet) → Details… → Proxies → Auto proxy configuration → paste the URL → OK.
            
    Linux / Firefox: Firefox Settings → Network Settings → Automatic proxy configuration URL (or GNOME Settings → Network → Network Proxy → Automatic).
            
    We're working on a signed Mac app and Chrome/Firefox extensions so this step will be automatic soon.
    • 
          
  • On a Mac: “Allow hogman to find devices on local networks?” Either answer works.
            Allow lets your devices in the same home or office talk to each other directly, which is faster.
            Don't Allow sends that traffic the long way, over the internet. Nothing on your network is shared with the pen either way.
    • 
        

        
Using a VPN (ProtonVPN, Mullvad, or a work VPN)? macOS VPN apps override the system proxy while connected.
          Pause your VPN while visiting pen sites, or set Firefox's built-in Automatic proxy configuration URL to the address printed by hogman.

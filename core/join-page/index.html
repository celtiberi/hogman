On a Mac, two things may pop up. Both are expected.

        
    
          
  • “Allow hogman-join to find devices on local networks?” Either answer works.
            Allow lets your devices in the same home or office talk to each other directly, which is faster.
            Don't Allow sends that traffic the long way, over the internet. Nothing on your network is shared with the pen either way.
    • 
          
  • Your Mac's password, once, so your browsers can find the pen's sites. It changes only that proxy
            setting. If you skip it, the tool prints the one setting to change by hand.
    • 
        

        
Using a VPN (ProtonVPN, Mullvad, or a work VPN)? macOS VPN apps override the system proxy while connected.
          Pause your VPN while visiting pen sites, or set Firefox's built-in Automatic proxy configuration URL to the address printed by hogman-join.

              Host something

              Hosting guide →

              One command puts a folder or a web server in the pen, with its own name and a real browser padlock. Run it with the same hogman you joined with, on a computer that's in the pen:

              ~/hogman share photos ~/holiday --note "Summer trip photos"
~/hogman share blog 3000            # a site you're building, by its port

              Everyone in the pen can then open https://blog.<network>.pens.hogman.network. Add --background to keep it running after the window closes; ~/hogman share stop blog takes it down and frees the name.

              Note: site names are publicly visible in certificate logs (contents stay private). Don't put anything sensitive in a site name.

              Running from a spare computer that isn't in the pen? Click Get a share link above and pass the link at the end: ~/hogman share blog 3000 '<share link>'. Already run Caddy or nginx? Share its port.

              Upgrading from an older hogman-join binary? Download ~/hogman from https://hogman.network/dl/hogman-$(uname -s)-$(uname -m), run chmod +x ~/hogman && ~/hogman update, then delete ~/hogman-join.

          Host something

          One command puts a folder or a website in the pen, with its own name and the padlock. Run it with the same hogman-join you joined with, on a computer that's in the pen:

          ./hogman-join share photos ~/holiday     # a folder, served as a website
./hogman-join share blog 3000            # a site you're building, by its port

          Everyone in the pen can then open https://blog.<network>.hogman. Add --background to keep it running after the window closes; ./hogman-join share stop blog takes it down and frees the name.

          A computer that isn't in the pen, like a spare box in the closet? Press Add a server above, and put its link at the end: ./hogman-join share blog 3000 '<server link>'.

          Running your own web server instead

          Add a server above, name it, and point Caddy (or any ACME client) at the pen's CA:

          {
	acme_ca https://ca.<network>.hogman:9000/acme/acme/directory
}
yourname.<network>.hogman {
	respond "hello"
}
